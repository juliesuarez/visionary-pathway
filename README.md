Visionary PathWays Website

A comprehensive, responsive website for Visionary PathWays, a community-based non-governmental organization (NGO) in Uganda dedicated to empowering youth through Sexual and Reproductive Health Rights (SRHR) education, entrepreneurship, and leadership training.

Features

Modern, Responsive Design: Fully optimized for desktops, tablets, and mobile devices using a custom CSS grid and flexbox layout.

Interactive Navigation: Sticky navigation bar with a mobile hamburger menu and a dedicated "Donate ❤️" call-to-action.

Dynamic Gallery Slider: An auto-playing image slider highlighting community outreach programs and interventions.

Integrated Outreach Reports: A dedicated section linking to interactive, browser-based slide presentations (e.g., Arise & Community Outreach Report).

Functional Contact Form: Pre-configured form linked to visionarypathwa@gmail.com using FormSubmit, including an auto-select feature for Donation inquiries.

Setup & Installation

This project is built using pure HTML5, CSS3, and Vanilla JavaScript. No complex build tools or frameworks are required.

Download or Clone the Repository: Save the files to your local machine.

Setup the Images Folder: Ensure all required images are placed in the images/ folder and match the file names referenced in the index.html and outreach_report.html files.

Run the Site: Simply double-click index.html to open it in your default web browser.

Contact Form Configuration

The contact form is powered by FormSubmit, a free service that connects HTML forms directly to your email inbox without needing a backend server.

To activate the form:

Open the website and fill out a test message in the Contact section.

Click "Send Message".

Check the inbox for visionarypathwa@gmail.com. You will receive an activation email from FormSubmit.

Click "Activate Form" in that email.

The form is now live! All future submissions will go directly to your inbox.
